# Eric Lin's Portfolio

A website to showcase my work and a little about myself! Built with [Next](https://nextjs.org/), [GSAP](https://gsap.com/), [Locomotive Scroll](https://scroll.locomotive.ca/), and [Three.js](https://threejs.org/). View the [live site](https://lineric.vercel.app/) deployed on Vercel.

## Fonts

[Geist](https://vercel.com/font)

## Deployment

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
